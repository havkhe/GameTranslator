## 二、这台机器上的两个坑（都会让人以为"工具坏了"）

1. **Python 不能写 `J:` 盘**（连 `J:\` 根目录都写不了，`PermissionError [Errno 13]`），但 **PowerShell 可以**。
   → 所以 evbunpack 的**输出目录必须放在 D:**，解包完再用 PowerShell 复制到游戏目录。
   （成因像 Windows Defender 的受控文件夹访问/驱动级写限制：同一路径 PowerShell 写得进去、这个 venv 里的 python 写不进去。）
2. **Windows PowerShell 把 `.ps1` 按 ANSI(GBK) 读**，所以 `.ps1` 里**不能出现任何非 ASCII 字符**——
   路径里的中文会变成乱码（实测报"路径不存在"），连提示文字里的中文都会让**语法**报错。
   → 需要 CJK 路径时，要么走 `powershell -Command "…"`（命令行参数是 UTF-16，正确），
   要么在 `.ps1` 里**只用 ASCII 字面量去"发现"路径**：
   `Get-ChildItem 'J:\game\HGAME\H' -Directory -Recurse -Filter '*SIGNIT*'`。

## 四、"有没有对白、翻到了没有"是怎么查的

1. **入库构成**（`signit-composition.js`，读抽取文件按 `path` 分类）：
   ```
   总计 18913 ：对白/事件 18155（含假名 18071） ／ 其它数据字段 726（574） ／ 菜单术语 32（15）
   ```
2. **翻译中的实时抽样**（`signit-pairs.js`，读管线日志里的 `PAIR` 行）：
   ```
   「私に必要なのはフレンドじゃなくてメンバーよ!!   →   「我需要的不是朋友，而是成员啊」!!
   \n<白根司令>\c[10]\{「グワアアアアアア～～～～～!!」 →  \n<白根司令>\c[10]\{「咕哇啊啊啊啊啊啊～～～～～!!」
   性的興奮だけに特化したショーツ\n日常的に履くのは…  →  只针对性兴奋特化的内裤\n日常穿着的只有经过调教的母奴隶而已
   ```
   控制代码（`\n<x>`、`\c[n]`、`\FF[n]`、`\>`、`\n[1]`）都原样保留 ✓。
3. **跑完后再做一次"残留检查"**（计划）：对打完补丁的 `www/data` 再统计一次"含假名的对白行"，
   与翻译前的 18,985 行对比，得出**真正还剩多少未汉化**——这就是你要的"防止出现未汉化的问题"的最终验收。
4. **为什么用本地模型而不是云端**：本地无内容审核；云端（百炼）对露骨内容会返回
   `data_inspection_failed`（实测约 4% 被拦，且拦截是确定性的）——那种被拦的条目**恰恰是最露骨的对白**，
   留在那里就是"未汉化"。所以这个游戏用本地模型翻，宁可慢。

## 五、第一次翻译被中断（模型服务被停掉）——结果与恢复办法

翻译跑到 916 条时，**模型服务（llama-server）被主动停止**，此后每一条请求都在网络层失败：

```
TOTAL 18913 DONE 0 PENDING 18913 REQUESTS 2365
TRANSLATED 916 FAILURES 18093 REQUESTS 227
PATCHED 974 MISSING 39393 FILES 13
DONE
failures 分类：request-failed 17987 ／ quality:unchanged 51 ／ code-invented 35 ／ already-chinese 6
日志里的错误只有一条：REQUEST_FAILED "read ECONNRESET"
```

**为什么护栏没有拦住补丁**：`pipeline/index.js` 的 `ALL_FAILED` 判据是
「待译>0 且 **本次没有产生任何译文**（`stats.cached <= cache.loaded`）且传输失败占多数」。
这次确实产出了 916 条，所以判据为假 → 它把已有的 974 串（名词/技能/术语等 13 个文件）打了进去，
退出码 0。**那 974 串是真译文，不是损坏**；对白一个字节没动。

**游戏现在的真实状态**（`signit-residual.js` 实测，这是"到底还剩多少没汉化"的验收口径）：

| | 翻译前（`data_原版备份`） | 现在（`www/data`） |
|---|---|---|
| 对白行（401） | 19,604 | 19,604（一行没丢） |
| **其中仍含假名** | **18,985** | **18,302** |
| 菜单术语（含假名） | 16 | 16 |

→ 目前只有约 **683 行对白**变成了中文，**对白还有 96.4% 是日文**（名词/技能等已有 974 串是中文）。

**没有丢任何东西，可以原地续跑**：
- `data_原版备份` 是未改动的原版（对白行数一致）→ 下一次仍以它为源；
- 缓存里有 916 条 ✓；
- 18,093 条失败里 **17,987 条是 `request-failed`，它们不进缓存** → 重跑时会自动重试 ✓。

**续跑步骤**：窗口里「启动模型」→ 重新勾选这一局 → 「开始汉化选中」（或把它加进队列）。
它会接着缓存继续，不会重译已完成的。

## 六、暂停标记为什么不撤

`work\paused.flag` 是我加的（为的是让队列给这次解包+翻译让路），**翻译被打断后我特意没有删它**：
模型服务现在是停的，一旦恢复队列，它正在跑的那一组会立刻变成一大堆 `request-failed`
（正是上面这一局刚经历的事）。所以**标记保持到模型重新启动为止**；要恢复队列就在窗口里点「继续」
（会删掉该标记，同时也会放行我这次留下的一切）。
