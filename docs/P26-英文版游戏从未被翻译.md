# P26 —— 英文版游戏从未被翻译：提取规则把非中日文全部丢弃

生成时间：2026-10-12
分支：`v3-p1`
起因：5 局英文版游戏显示"已完成"却没有翻译 —— `LewDemon Academy(eng)`、`Luxuria [ENG]`、
`NTR Gyaru`、`NTR Police ver1.10`、`NTR Sisters - Ciella & Luciella`
新增单测：`tools/unit-english-source.js`（31 项）

---

## 一、结论

**不是"翻译文件没应用"，而是英文正文从来没被抽取过。** 这 5 局都是英文版（拉丁字母占 95.8%–99.7%），
而提取规则里有一行 `if (!CJK_RE.test(t)) return false;   // 没有中日文 → 不是我们的目标`，
于是**整部正文被丢弃**；剩下的只有游戏里残留的日文（战斗/技能名之类），翻完那些，
流水线退出码 0、界面显示"已完成"，而玩家读到的每一行都还是英文。

## 二、证据

| 游戏 | 现役文本（假名/汉字/拉丁） | 我们抽取 | 翻译报告 | 补丁写入 |
|---|---|---|---|---|
| LewDemon Academy(eng) | 1.1% / 3.1% / **95.8%** | 757 条 | entries 764、translated 181、failures 1,864 | VXAce 替换 222 处 |
| Luxuria [ENG] | 1.0% / 2.1% / **96.9%** | 190 条 | entries 190、translated 138、failures 121 | VXAce 替换 8 处 |
| NTR Gyaru | 0.6% / 0.5% / **98.9%** | 88 条 | entries 88、translated 85、failures 5 | MV |
| NTR Police ver1.10 | 0.2% / 0.3% / **99.6%** | 839 条 | entries 839、translated 717、failures 364 | MV |
| NTR Sisters - Ciella & Luciella | 0.1% / 0.2% / **99.7%** | 645 条 | entries 645、translated 562、failures 288 | MV |

失败原因几乎全是 **`quality:unchanged`**（LewDemon 1,837/1,864、NTR Sisters 271/288、NTR Police 317/364）：
抽出来的那些条目本来就是"看起来像中文的汉字词"（`剣術`、`格闘/物理`），模型原样返回 → 被判"未翻译"，
真正需要翻的英文**根本没进任务**。

## 三、修复

1. **英文正文规则**（`pipeline/extract/rules.js` 新增 `isTranslatableEnglish`）：
   ≥2 个词，或"单个词 + 句末标点"（`Yes.` `No!` 这类选项）；以字母为主（≥60%）；
   并沿用原有排除：资源文件名、引擎类名、事件 id、纯 ascii 的 id/路径/数字、URL、路径分隔符。
   单个裸词（`Potion`）按 id 处理不发送——它更可能是标识符而不是台词。
2. **`translatableSource` 同步**（`pipeline/translate/quality.js`）：英文源也要有 `unchanged` 检查，
   否则模型回显英文会被当成"合格译文"入库——这正是以前英文局没有防线的地方。
3. **英文源的译文必须是中文**（`looksLikeEnglish`）：原来的判据是"译文里的英文字母比原文多出来的部分"，
   面对英文源恒为 0（原文本来就有那些字母），英文**改写**也会被放过；现在英文源的译文必须含汉字。
4. **提示词不再写死"日文"**：内置默认模板与 `D:\GameTranslatorV3\work\prompt.txt` 都改成
   "将下列每行文本翻译成简体中文（**原文可能是日文，也可能是英文**）"。模板仍是可改的。

## 四、验证

- `tools/unit-english-source.js`：31 项断言（英文正文必须抽取；id/文件名/路径/URL/单字仍排除；
  `Yes.` 算台词；日文规则不受影响；英文源的回显/改写被拒、中文译文通过；真实语料抽查）。
- 真实语料：NTR Sisters 的原版数据里有 **49,000 条含英文的字符串，规则接受 39,246 条（80%）**
  —— 这就是过去被整批丢掉的量级。
- 全部 16 个单测套件 `fail 0`。

> 取舍：规则偏宽松是有意的（`rules.js` 顶部注释说的"太聪明的规则会静默丢对白"）。
> 代价是会带上少量"多词但非对白"的配置串（例如插件参数里的 `scene: battle`）——
> 宁可多翻一点，也不要漏掉正文。

## 五、这 5 局怎么收尾

它们的缓存仍然有效（里面是那 181/138/85/717/562 条），但**英文正文一条都没有**，所以：
**直接重跑即可**（抽取这一步就会多出成千上万条英文正文 → 进翻译 → 打补丁）。
不需要还原、不需要删缓存。等模型空闲时跑（当时程序正在翻《鉄脚のカエン》，没有抢）。

另外提醒：`work\prompt.txt` 已被改成"日文或英文"版本——如果你曾在界面里自定义过提示词，
现在这份是带英文支持的版本；想改回只翻日文也行，把那句改回去即可。
