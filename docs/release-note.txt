# 🎮 GameTranslator v2.3.2（正式版）—— 确定按钮 + 热切换提示

> **v2.3.2 为最新正式稳定版**（v2.2.6 / v2.3.0 / v2.3.1 仍可下载）。

## 📥 下载 / Downloads

- `GameTranslator-v2.3.2-Vulkan-Generic.zip` —— Vulkan 通用版，适合 GTX 10 系列及各种支持 Vulkan 的显卡（NVIDIA / AMD / Intel）
- `GameTranslator-v2.3.2-CUDA12-RTX.zip` —— CUDA 12.4 版，适合 NVIDIA RTX 20 / 30 / 40 / 50 系列（sm_70+）

## ✨ 本版更新

- **llama 高级设置新增“确定修改llama设置”按钮**：切换预设或修改参数后，
  点击该按钮（或底部“保存”）才会写入并生效；对话框同时保留“取消”可全部丢弃。
- **明确热切换限制**：llama 不支持运行中热切换模型或参数。
  切换模型时日志会提示“将在下次开始汉化时自动重启并加载新模型”；
  设置页会提示“修改后需重启 llama 生效”；保存后弹窗会说明新参数在下次汉化时应用。
- RTX 内置最优预设（自动检测 RTX + FlashAttention + q8_0 KV + 2048/512 批次 + 4 线程 + 关闭轮询）
- 设置保存失败时明确报错，并在程序目录不可写时自动改存到 `%APPDATA%\GameTranslator\settings.json`
- 自定义翻译提示词（默认预填，支持 `{lines}` 占位符）
- 菜单栏 + 双行工具栏 + 右侧可折叠设置面板
- RPG Maker MV / MZ / VX Ace 内嵌式汉化、断点续翻、检查翻译、原版/汉化一键切换、llama 启停释放显存

## 🚀 使用方法

1. 解压到任意目录；
2. 将 GGUF 模型放入 `D:\galtrans`（或启动后设置模型目录）；
3. 运行 `GameTranslator.exe`；
4. RTX 用户直接开始汉化即可；也可到 设置 → llama 高级设置 选择预设或手动微调。

# 🎮 GameTranslator v2.3.2 (Stable) — Confirm Button + Hot-Switch Notice

> **v2.3.2 is the latest stable release** (v2.2.6 / v2.3.0 / v2.3.1 remain downloadable).

## 📥 Downloads

- `GameTranslator-v2.3.2-Vulkan-Generic.zip` — Vulkan generic build for GTX 10-series and any Vulkan-capable GPU (NVIDIA / AMD / Intel)
- `GameTranslator-v2.3.2-CUDA12-RTX.zip` — CUDA 12.4 build for NVIDIA RTX 20 / 30 / 40 / 50 series (sm_70+)

## ✨ What's New

- **Explicit "Apply llama settings" button** in llama Advanced Settings: switching a preset or editing
  parameters only takes effect after pressing this button (or Save); Cancel discards everything.
- **Hot-switch limitation is now clearly communicated**: llama cannot hot-swap models or settings at runtime.
  Switching models logs a notice that the server will restart with the new model on the next translation;
  the settings page shows a reminder, and the save dialog states that new parameters apply on the next run.
- Built-in RTX preset (auto-detected RTX + FlashAttention + q8_0 KV + 2048/512 batch + 4 threads + polling off)
- Visible save errors with fallback to `%APPDATA%\GameTranslator\settings.json` when the program folder is read-only
- Custom translation prompt (pre-filled default, `{lines}` placeholder)
- Menu bar + two-row toolbar + collapsible right settings panel
- In-place localization for MV / MZ / VX Ace, resume, translation check, original/localized switching, llama on/off to free VRAM

## 🚀 Usage

1. Extract to any folder.
2. Put GGUF models into `D:\galtrans` (or set the model directory in the UI).
3. Run `GameTranslator.exe`.
4. RTX users can start right away; tune settings via Settings → llama Advanced if needed.
