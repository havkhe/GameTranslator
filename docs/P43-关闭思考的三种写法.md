# P43 —— 关闭思考链有三种写法，程序现在会依次试（含 API 自检工具两项）

生成时间：2026-10-13
触发：用户日志

```
15:27:19  API_THINK_FLAG_OFF deepseek-ai/deepseek-v4.1-flash 不接受 enable_thinking，已去掉该参数继续翻译
15:27:43  REQUEST_FAILED "thinking-only reply: 514 chars of reasoning_content and no answer"
```

---

## 一、根因：`enable_thinking` 恰好是这个端点唯一不收的写法

链路：NVIDIA 端点对这个模型**拒收 `enable_thinking`（HTTP 400）** → 程序按设计去掉它重试 →
**思考没被关掉** → 模型把整个输出预算花在 `reasoning_content` 上 → `content` 为空 →
报 `thinking-only reply` 并把该行记为失败。而**这一类失败原本不会换链上的下一个模型**
（只有 403 额度、404 模型不存在才换），所以它会对着同一行反复失败。

**实测四组参数（同模型同提示）：**

| 组合 | 结果 |
|---|---|
| `max_tokens=1024`（原状） | 60.4 s，正文 **0** 字，思考 2669 字，`finish=length` ← 复现失败 |
| `max_tokens=4096` | 117.5 s，正文 **0** 字，思考 **10519** 字，`finish=length` ← **调大预算没用，它只会想更久** |
| `chat_template_kwargs:{thinking:false}` | 39.1 s，**正文 40 字，思考 0 字** ✅ |
| `reasoning_effort:"none"` | 32.4 s，**正文 37 字，思考 0 字** ✅ |

所以**关思考有三种写法，而各家只认其中一部分**：
`enable_thinking`（Model Studio 的写法，程序一直发的就是这个）、
`chat_template_kwargs:{thinking:false}`（llama.cpp / vLLM 系）、`reasoning_effort:"none"`。

## 二、改了什么（`pipeline/translate/client.js`）

1. **依次尝试三种写法**：`enable_thinking` → `chat_template_kwargs` → `reasoning_effort` → 都不行才作罢。
   用一个模块级 `apiThinkOffMode` 表示当前用的是哪种；收到 400 且错误信息里点名了当前这种写法时，
   换下一种**重试同一条**（不换模型——这是参数问题）。日志会写清换成了哪种。
2. **只回思考内容时换链上下一个模型**：`content` 为空而 `reasoning_content` 非空，且链上还有别的模型时，
   切换过去重试（和 403/404 的处理一致，每条请求最多切一次），不再把整批记为失败。
   链上确实没有可换的模型时，错误里会写明「链上没有别的模型可换」。
3. `resetApiModel()` 一并复位这个模式。

单元测试（`tools/unit-api-mode.js`）新增 11 条：三种写法依次出现、每次都不再带上一种、
全程发给同一个模型；以及「只回思考 → 换到 model-b 并拿到译文」「链上没得换时仍报 thinking-only 且说明无模型可换」。
**全量 17 个 unit 文件 458 项通过、0 失败**（其中 api-mode 66 项）。

## 四、顺带交付的两个工具

- `tools/api-check.js`：给地址即检测①地址合法性（含 DNS 解析后的内网/回环拦截）②`/models` 与密钥鉴权
  ③**真发一条翻译请求**并按四类失败给出处理办法（401/403 密钥·额度、404 无权限、400 拒收思考开关、
  只思考不给译文、返回了但没中文）。
- `tools/api-models.js`：自动抓模型目录（按程序内置规则剔除向量/重排/视觉/语音/图像类），
  `--probe` 逐个真发短请求标出「可用/不翻/只思考/无权限/密钥/限流/超时」，
  最后按实测延迟给出**可直接粘进「模型链」的一行**。串行探测，用 `--only`/`--limit` 控范围。
- 两者都**只从环境变量读密钥**（默认 `GT_API_KEY`），地址默认拒绝本机/内网（本机服务加 `--allow-local`）。
