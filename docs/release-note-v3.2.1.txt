# GameTranslator v3.2.1 —— 云端接口认错模型名不再"每行都失败"，报错也终于说得清原因

> **v3.2.1 是 v3.2 的修错版**：只改云端模式的错误处理，不引入新功能，翻译本身一行未动。
> 依然只有一个包（Vulkan 与 CUDA 12 两套后端都在里面），覆盖升级即可。
> **只用本地模型的用户：本版对你的行为没有任何变化。**

## 一、下载 / Downloads

- `GameTranslatorV3-v3.2.1.zip` —— **解压即用**：主程序 + 管线 + 工具 + 内置 node 与 ruby
  + **两套 llama.cpp 后端**（`llama\vulkan\` 与 `llama\cuda12\`），切换只改一个设置、离线即可。
- 覆盖升级即可，**设置与密钥不会丢**：`ui-settings.ini`、`api-config.json`、`work\` 都不在包里，
  已翻好的记录也不会被动。

## 二、修了什么

### 1. 云端模式：接口不认识链上第一个模型名时，现在会自动换下一个（而不是每行都失败）

**症状**：翻译时日志刷满 `REQUEST_FAILED "API returned no content (HTTP 400)"`，一行都没翻出来，
看起来像是"接口挂了"或"设置没保存"。

**原因**：模型链的第一位取自【设置…】里的「模型」栏，而它可能还是**上一个接口留下的名字**
（例如从别的云端换成 Index-Translate 之后）。接口对这个名字回 400「未知模型」，
但客户端的"端点不认识这个模型 → 换链上下一个"判别只认 `不存在` / `not found` / `unknown`，
**唯独不认 `未知`**——于是降级逻辑不触发，排在第二位、本来完全正确的模型永远轮不到，
每一次请求都撞死在同一个 400 上。

**现在**：识别 `未知模型`（以及"公开支持模型"这类说法），自动换到链上下一个模型并重试**同一条请求**，
日志里会留下一行：

```
API_MODEL_SWITCH google/diffusiongemma-26b-a4b-it -> Index-Translate-35B-A3B
   （该端点不认识这个模型名，继续用 Index-Translate-35B-A3B 翻译）
```

同一条请求重试，不丢进度、不记失败。链上再没有可换的模型时，报错会说明"免费额度都用完了"或列出整条链。

### 2. 报错信息带上服务端的原话

以前任何 400 都只剩一句 `API returned no content (HTTP 400)`——**只说症状，不说原因**。
现在会把服务端返回的 `detail` / `message` / `error` 原文接在后面，例如：

```
API returned no content (HTTP 400) — 未知模型 'x'，公开支持模型: Index-Translate-35B-A3B, index-mt-2b, …
```

以后再遇到云端报错，原因直接写在日志里，不用靠猜。

### 3. 测试

`tools\unit-api-mode.js` 增加 8 项断言（72 → **80**）：`未知模型` 措辞识别、降级确实发生、
报错带出服务端原话、以及"配额措辞不会被误判成模型名错误"这条反向用例。
全套 **18 个单元测试文件、482 项断言全部通过**。

## 三、给云端用户的两点实测提示（不是本版改动，但值得知道）

- **免费公共接口不需要密钥**。例如 Index-Translate 的公共接口（`https://index-translate.bilibili.com/v1`），
  密钥栏填任意字符串即可，服务端会忽略这个头；但翻译器的云端模式要求密钥非空，所以别留空。
  该接口单次请求输入上限 16384 token，超出会明确报错。
- **批量行数建议保持默认 8**。批量由环境变量 `GT_BATCH`（默认 8 行）与 `GT_BATCH_CHARS`（默认 900 字符）决定。
  在 300 行真实语料上实测：8 / 16 / 30 / 60 行的吞吐都在 5.5~6.7 条/秒之间，**没有实质差别**；
  但批次越大，偶发"整批原样返回日文"的比例越高（8 行约 5%，30 行约 8~14%，且出问题时一批能有 20+ 行），
  100 行还会顶到接口 4096 输出上限，导致整批被拒、只交出三分之二的行。

## 四、已知限制

- 云端模式需要联网。免费公共接口**没有公开的配额与 SLA**，随时可能限速、变更或下线，
  建议保留本地模型作为兜底（同一个游戏重跑会走缓存，不会重翻）。
- 云端翻译意味着**该游戏的全部文本都会发到第三方服务器**，介意这一点就用本地模型。
- "整个目录可以搬走"的自愈逻辑只作用于设置文件里的路径；搬动安装目录后，失效的绝对路径会回落到默认值
  并在日志里提示一句。
