## 一、改了什么

队列面板里那个下拉框（`cmbTargetGroup`，原本只是"加入选中到所选组"的目标选择）现在**就是队列的总览**：

- **每一行是一组的总览**：`第 N 组 [状态 完成/总数] 失败x 跳过y　成员名…`
  例如你现在队列里的第一行（UiCheck 实测输出）：
  ```
  第 1 组 [等待 0/40]　(同人ゲーム)[金色complex] 剣鬼バルゴ～有名将校衝撃のAVデビュー!～Ver24.02.25、…
  ```
- **默认选中第 1 组**（原来是选中最后一组）—— 面板从上往下读，先问到的就是第一组；
- **下拉比输入框宽**（`DropDownWidth = 520` vs 输入框 132 px），否则一行总览会被截掉一半；
- **悬停提示把选中那一组整个写出来**：组状态 + 逐个任务一行（最多 12 个，多了写"其余 N 个"），
  所以"第一组里有什么"不用展开树也能看到；
- 切换下拉选项会即时更新提示（`SelectedIndexChanged → UpdateTargetGroupTip()`）。

组的状态、完成数、失败/跳过数与上方的队列树**同一套口径**（都读 `grp.State` / `Task.Result`），
所以下拉、树、摘要行三处永远一致。
