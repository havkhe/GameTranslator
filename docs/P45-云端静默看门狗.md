# P45 —— 云端慢模型被自己的看门狗掐断，报出来却是 `read ECONNRESET`

生成时间：2026-10-13
触发：用户在【设置…】→ 连接测试里点「测试连通性」，得到

```
③ 对话   模型 deepseek-ai/deepseek-v4.1-flash ……
API_THINK_FLAG_OFF deepseek-ai/deepseek-v4.1-flash 不接受 enable_thinking，改用 chat_template_kwargs 重试同一条
   ✗ 失败：read ECONNRESET
```

---

## 一、根因：45 秒"静默看门狗"掐的是自己

`pipeline/translate/client.js` 里有一个看门狗：**响应开始后 45 秒没有任何字节到达就 `req.destroy()`**
（`STALL_MS`，为本地 llama-server 设计的——它是一边算一边吐 token，45 秒不出字确实是卡死）。
但云端完全是另一种节奏：`stream: false` 的推理模型**一个字都不发，最后一次性把整段回答送回来**，
实测这个模型单次请求 32~215 秒。于是看门狗在读第一行之前就把 socket 掐了，
Node 把这**自己造成的**中止报成 `read ECONNRESET`——看上去像网络故障，其实是程序自己动的手。

**复现（决定性）**：把窗口临时调小到 3 秒再跑同一个检查，得到**一模一样**的
`read ECONNRESET`（连 `API_THINK_FLAG_OFF` 换参数那一步之后的时机都一样）：

```
> set GT_API_STALL_MS=3000 & node tools\api-check.js https://integrate.api.nvidia.com/v1 --model deepseek-ai/deepseek-v4.1-flash
③ 对话   模型 deepseek-ai/deepseek-v4.1-flash ……
   ✗ 失败：read ECONNRESET          ← 与用户看到的一致
CHECK=fail
```

（之前命令行那次成功，是当天端点恰好回得比 45 秒快，属于侥幸。）

## 二、改了什么

`STALL_MS` 拆成两个窗口，按端点类型取：

| 环境变量 | 默认 | 用在哪 |
|---|---|---|
| `GT_STALL_MS` | 45 秒（不变） | 本地 llama-server（一边算一边吐，45 秒不出字就是真卡死） |
| `GT_API_STALL_MS` | **300 秒** | 云端（一次性回包，静默是正常的） |

实现成一个**按调用读取**的小函数，便于测试：

```js
function stallWindowMs(isApi) {
  if (!isApi) return parseInt(process.env.GT_STALL_MS || "45000", 10);
  return parseInt(process.env.GT_API_STALL_MS || "300000", 10);
}
```

外层仍有兜底：管线自己的 `StalledAfterMinutes`（默认 10 分钟）才是云端一局的硬上限，
所以把内层放宽到 5 分钟不会让真卡死的端点无限挂着。
代价说清楚：真挂死的云端端点，现在要 5 分钟才放弃（以前 45 秒）——要更短就设 `GT_API_STALL_MS`。

## 三、验证

- **改前/改后对照（同一个端点、同一个模型）**：
  - `GT_API_STALL_MS=3000` → `✗ 失败：read ECONNRESET`（复现用户的报错）
  - 默认 300 秒 → `API_THINK_FLAG_OFF … 改用 chat_template_kwargs` ⇒ **214.9 秒后拿到中文** ⇒ `CHECK=ok`
- **单元测试**：`tools/unit-api-mode.js` 新增 6 条（本地 45 秒 / 云端 300 秒 / 云端至少是本地 3 倍 /
  两个环境变量各只改自己那一边 / 删掉变量回到默认）。**全量 17 个 unit 文件 464 项通过、0 失败。**
- 已把 `pipeline/translate/client.js` 与 `tools/unit-api-mode.js` 同步到 `D:\GameTranslatorV3\`
  （哈希一致）——**下一次翻译与下一次点按钮就生效**，不用重编译 exe。

## 四、顺带一句实话

这个模型即使全修好也**不适合批量翻译**：单次 2 行文本要 54~215 秒（本地 4B 是 3~5 秒）。
连接测试现在会如实告诉你能不能翻，但"能用"和"值得用"是两件事——
挑模型请用 `tools\api-models.js --probe`（会按实测延迟排序），或设置里那个「检测可用模型」按钮。
