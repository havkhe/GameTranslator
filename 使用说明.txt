RPG Maker 汉化管理器（GameTranslator.exe） v2.3.2
==============================================

【v2.3.2 更新说明】
  - llama 高级设置界面新增醒目的“确定修改llama设置”按钮，
    并保留底部“保存 / 取消”按钮；修改后必须确认才会生效。
  - 明确告知热切换限制：llama 不支持运行中热切换模型或参数，
    切换模型或修改参数后，llama 会在下次开始汉化时自动重启并应用新配置；
    界面中（设置页提示、模型切换日志、保存结果弹窗）均会给出相应提示。

【v2.3.1 更新说明】
  - 新增 RTX 内置最优预设：检测到 RTX 显卡且未手动调整过 llama 参数时，
    自动启用 FlashAttention + q8_0 KV 缓存 + 2048/512 批次 + 4 CPU 线程 +
    关闭轮询；也可在“llama 高级设置”中手动选择
    “RTX 高性能 / 通用均衡 / 省显存 / 自定义”预设。
  - 高级设置界面明确“点保存才生效”：修改参数后必须点击“保存”，
    取消则全部丢弃；保存成功/失败都会弹出明确提示。
  - 修复设置保存：若程序目录不可写（如只读目录），设置自动改存到
    %APPDATA%\GameTranslator\settings.json，不再静默丢失。

【v2.3 更新说明】
  - 新增 llama 高级设置（CUDA 用户可自行调节）：上下文长度、GPU 层数、
    批大小、物理批大小、CPU 线程数、轮询等级、FlashAttention、
    K/V 缓存类型、服务端口、llama 内存上限。
  - 修复 CUDA 模式 CPU 占用暴增：GPU 模式默认把 CPU 线程限制为 4 并关闭
    轮询等待（--poll 0），显著降低 CPU 空转；仍可在设置中自行调整。
  - 新增翻译提示词自定义：设置中默认填入默认提示词，支持 {lines} 占位符
    （自动替换为待翻译的编号行）；留空保存将恢复默认提示词。
  - UI 优化：新增菜单栏（文件/翻译/设置/帮助）、顶部双行工具栏、
    右侧可折叠设置面板，不再把所有按钮挤在一排。
  - 运行设备选择移入右侧设置面板；llama 参数改动后重启服务即生效。

【v2.2.5 更新说明】
  - 新增“检查翻译”：扫描选中游戏，找出翻译不全（译文残留日文/英文/未变化）
    与未翻译的内容，可一键重新翻译。
  - 新增“卸载汉化”（还原原版）与“恢复汉化”（切回汉化版）：
    汉化完成后自动备份 data_汉化备份，与原版备份 data_原版备份 自由切换；
    游戏目录同时生成“一键还原汉化前.bat”与“一键恢复汉化.bat”。
  - 修复一键还原 bat：改为 UTF-8 + chcp 65001，解决中文路径在部分系统
    （代码页 65001）下不生效的问题。
  - 新增“停止llama/启动llama”按钮：待机不翻译时可手动停止服务，
    释放显存；再次翻译会自动重新启动。

【v2.2.2 更新说明】
  - 内置 llama 改用 Vulkan 后端：新版 CUDA 预编译包已不支持 GTX 10 系
    （Pascal），会静默退回 CPU；Vulkan 版可让 GTX 1060 等老显卡真正使用 GPU。
  - 界面新增“运行设备”下拉：显示检测到的真实 CPU / GPU 型号
    （如 GPU (NVIDIA GeForce GTX 1060 6GB)），可选 GPU 或 CPU 运行；
    默认 GPU（-ngl 99），CPU 模式不加载显存（-ngl 0）。
  - 新增 llama 内存硬限制：启动时通过 Windows 任务对象限制进程内存，
    默认自动 = 总内存 - 4GB（本机 16GB → 上限 12GB），可在 settings.json
    的 MaxMemoryMB 调整（0=自动）。同时限制 batch 大小降低内存峰值。

【v2.2 更新说明】
  - 内置 llama.cpp（CUDA/GPU）运行时，点“开始汉化”自动加载所选模型，
    无需再手动启动 Ollama；退出软件时自动停止；切换模型自动重启。
  - 已删除全部联网翻译 / API 相关功能（不再需要 API 地址、密钥）。
  - “扫描 K:\”改为盘符下拉 + “扫描”，或“选择文件夹”自定义扫描目录。
  - 模型下拉自动检测模型目录中的 *.gguf（默认 D:\galtrans），
    可点“模型目录…”选择其他位置，点“刷新模型”重新扫描。
  - 新增“暂停 / 继续”与“终止”按钮：暂停在批次间生效，终止保留进度可续翻。
  - 设置保存在 settings.json（模型目录、端口）。

一、支持的引擎
  - RPG Maker MV / MZ（www\data 下的 json 数据）
  - RPG Maker VX Ace（Data\*.rvdata2 散装数据，或加密包 Game.rgss3a，
    会自动解包 → 汉化 → 重新打包，并保留原版加密包备份）

二、模型
  - 模型为 GGUF 文件，默认从 D:\galtrans 加载（可改）。
  - 内置 llama.cpp Vulkan 版，自动使用独立显卡推理（GTX 10 系等老卡可用）。

三、使用方法
  1. 选择盘符点“扫描”，或“选择文件夹”/拖拽 Game.exe 加入游戏列表。
  2. 选择模型（自动列出模型目录中的 GGUF）。
  3. 点“开始汉化选中”或“全部汉化”；第一次会自动加载模型（等待就绪）。
  4. 汉化前自动备份：游戏目录下生成 data_原版备份 和“一键还原汉化前.bat”，
     出错时双击该 bat 或点“一键还原选中”即可恢复原版。
  5. 暂停 / 继续：批次间生效；终止：保存进度后停止，可断点续翻。
  6. 断点续翻：中断后重新对同一游戏执行汉化，会自动跳过已翻译的条目继续。
  7. 检查翻译：选中游戏点底部“检查翻译”，发现未翻译/翻译不全后可立即重翻。
  8. 底部“停止llama”可手动释放显存；“卸载汉化/恢复汉化”在原版与汉化版间切换。

四、说明
  - 已汉化（中文明显多于日文）的游戏会被自动跳过。
  - 非 RPG Maker 游戏不会被识别，也不会被改动。
  - 目录结构：GameTranslator.exe（界面）、game-pipeline.js（汉化管线）、
    llama\（内置 llama.cpp 运行时）、ruby\（便携 Ruby，处理 .rvdata2）、
    vxace_*.rb（VX Ace 数据读写）、rgss3a.js（Game.rgss3a 解包/重打包）。
  - 翻译进度保存在软件目录 work\<游戏名>-translations.json。
